カレンダーを尊重してくれる協力型RPGを見つけるのは、思っている以上に難しい。そして、まさにその問題を検証するのがこのWyldheartレビューだ。Wayfinder Studiosのデビュー作は、テーブルトップ風の冒険とサバイバルゲームの戦闘を融合させ、さらにその両方を、友人のグループが実際にクリアできるほど短いキャンペーンに包み込んでいる。グループの予定調整を無視したWyldheartレビューは本質を外してしまう。なぜなら、ほとんどのマルチプレイヤーキャンペーンを殺すのは難易度ではなく、スケジュール調整だからだ。

Wyldheartは、EA DICE、Embark Studios、Mojang Studiosでの経歴を持つベテランたちが設立したWayfinder Studiosの第一作で、*Star Wars Battlefront II* などの作品に関わったメンバーも含まれる。クリエイティブディレクターのDennis BrännvallとマーケティングディレクターのErin Bowerが、ゲームの正式発表前に初期ビルドをプレス向けに案内したが、その説明は一貫していた。より短い冒険、より小さなコミュニティ、そして本当の意味での達成感だ。

## Wyldheartとは？

Wyldheartは、終わりのない1つのキャラクターセーブではなく、独立した自己完結型キャンペーンを中心に据えた協力型アクションRPGだ。各キャンペーンはメインストーリーが約10時間、マップの隅々まで探索したいグループ向けの任意コンテンツが約15時間と予定されている。

この構造こそが売りだ。4人の大人に6か月間同じ火曜の夜を守れと求める代わりに、Wyldheartは1つの冒険にコミットすることを求める。クリアしたら、同じグループで新しいキャンペーンを始めてもいいし、キャラクターをまったく別の友人たちとのプレイに持ち込んでもいい。

| 特徴 | 初期ビルドで確認できたこと |
|---|---|
| スタジオ | Wayfinder Studios（デビュー作） |
| キャンペーン長 | メインストーリー約10時間、任意コンテンツ約15時間 |
| パーティ人数 | 最大4人 |
| マルチプレイ形式 | ドロップイン／ドロップアウト |
| セーブ | グループ間でクラウド共有 |
| 進行 | クラスレス、グループXP |
| 難易度 | プレイヤー人数に応じてスケール |
| ワールドマップ | ボードゲームにインスパイアされたヘクスグリッド |
| キャッチアップシステム | 搭載済み。セッションを逃してもグループが停滞しない |

繰り返す価値のある注意点が1つある。これらの数値はプレス向けに公開された発売前ビルドのものであり、ローンチ前に数字や機能が変わる可能性がある。コミュニティの報告がまだ少ないのは、単にゲームが発表されたばかりだからだ。

## キャラクター作成とクラスレス進行システム

各キャンペーンはキャラクター作成から始まる。祖先、背景、外見オプションを選び、最初のダンジョンがロードされる前から、機械的な出発点と物語的な味付けの両方を与えられる。

### 「クラスレス」が聞こえる以上に重要な理由

Wyldheartはクラスに固定しない。背景は方向性を示唆する――特定の生い立ちは支援ツールや重い武器へと後押しするかもしれない――が、まったく別の方向へ進むことを妨げるものは何もない。レベル1で「間違った」アーキタイプを選んだせいで作り直すのが嫌いなプレイヤーにとって、この柔軟性は意味のあるQoL面での勝利だ。

| 選択項目 | 形作るもの | 固定されるか |
|---|---|---|
| 祖先 | キャラクターのアイデンティティとフレーバー | いいえ |
| 背景 | 推奨される開始方向 | いいえ ― 従っても逸れてもよい |
| 外見 | 見た目 | 該当なし |
| 武器ロードアウト | 5つのクイックスロットのうち2つ | いいえ ― 自由に交換可能 |
| ユーティリティアイテム | 残り3つのクイックスロット | いいえ ― 自由に交換可能 |

代償は選択麻痺だ。クラスという錨がないため、最初の1時間は自由すぎると感じられるかもしれず、初期ビルドはほとんど手助けをしてくれなかった。自分の役割をはっきり示すラベルが欲しいタイプなら、グループで飛び込む前に数分間ツールチップを読む時間を確保しよう。

## 希望（ホープ）メカニクスの解説

Wyldheartレビューを定義するシステムが1つあるなら、それは希望だ。各キャラクターは体力バーの上に表示される5つのハートから始まり、これらのハートは散々な夜と死んだ英雄の間のバッファーとして機能する。

戦闘不能になるとハートを1つ失う。真夜中の移動でもハートを1つ失うため、ルート計画は形式的なものではなく本当の決断になる。町では失ったハートを回復できるので、賢いパーティは集落への訪問を買い物だけでなくメンテナンスとして扱う。

| 残りハート数 | 状態 | プレイ上の意味 |
|---|---|---|
| 5 | 満ちた希望 | 通常の冒険、ペナルティなし |
| 1～4 | 希望低下 | 警告サイン。町に寄り道して回復すべき |
| 0 | 希望なし | 次の戦闘不能でキャラクターが死亡する |
| 死亡 | 敗北 | 寺院または復活スクロールで蘇生 |

死は必ずしも永続ではない。ここにテーブルトップの影響が表れる。仲間は倒れたキャラクターを寺院まで運ぶか、復活スクロールを使って蘇生できる。あるいはプレイヤーはまったく新しいキャラクターを作成してパーティに再参加し、最終的にはその新入りを使って元の自分の英雄を救出することもできる。これは、多くの協力型キャンペーンを悩ませる「自分のキャラが死んで、今から2時間ただ座っているだけ」問題への、驚くほどエレガントな答えだ。

## マルチプレイ、ダンジョン、戦利品

マルチプレイは明らかに現実のスケジュール混乱を前提に設計されている。最大4人がドロップイン／ドロップアウトでき、セーブはクラウド共有され、XPはグループ全体でプールされ、難易度はパーティ人数に応じてスケールし、キャッチアップ機構によってセッションを逃した人が永久に遅れを取ることはない。

| マルチプレイ機能 | 実際に重要な理由 |
|---|---|
| ドロップイン／ドロップアウト | 全セッションに参加を約束する必要がない |
| クラウド共有セーブ | どのプレイヤーでも進行を失わずにホストできる |
| グループXP | サポート役をプレイしても罰を受けない |
| 難易度スケーリング | 2人でも4人でも公平な戦いになる |
| キャッチアップ機構 | 1週間逃しても役立たずのキャラクターにならない |
| マルチプレイ対話投票 | パーティで物語の返答を一緒に決める |

### ミニマップなしのダンジョン

Wyldheartはプレイヤーを空間に没入させるため、ダンジョンからミニマップを意図的に排除している。代わりに、ウェイマーカーを置くか、松明に火をつけてすでに制圧した部屋の目印として使うことが推奨される。序盤のスライムダンジョンでは、飛び込める穴が隠されており、戻るためのロープが用意されていた。

この設計判断は諸刃の剣だ。本物の探索と、「待って、あの通路はどっちだった？」という記憶に残る瞬間を生む一方、方向感覚に自信がないグループは余分にさまよう時間を見込むべきだ。

### 戦利品、耐久度、即席武器

このビルドは戦利品に関して寛容で、環境各所に武器やアイテムを散りばめ、敵からもさらにドロップした。耐久度は要素の1つで、武器は一定回数使うと壊れるため、予備を持ち歩くことは任意ではない。

| 武器カテゴリ | 初期ビルドで確認 | 実用上のメモ |
|---|---|---|
| 剣 | はい | 信頼できる近距離の定番 |
| 斧とメイス | はい | より重量級の近接オプション |
| 弓 | はい | 敵を引き寄せる遠距離オプション |
| 盾 | はい | ブロック用の防御スロット |
| 即席武器 | はい（大きな大腿骨を含む） | 遊び心のある戦利品テーブルを示唆 |

ダンジョンのクライマックスは巨大スライムボスで、環境への注意力が報われる戦いだった。火に弱いため、アリーナ周辺に置かれた火鉢を掴んで投げると、正面から殴り合うよりはるかに速くダメージを与えられた。

## ワールドマップ、キャンプ、ダウンタイム

序盤のダンジョンから脱出すると、冒険は明らかにボードゲームにインスパイアされた六角形のワールドマップへと広がる。すべてのヘクスを探索でき、町やダンジョン以外にも、手続き生成の埋め草ではなく、手作りされたイベントやシーンの数々が見つかる。

キャンプはマップにダウンタイムのリズムを与える。野営すると、料理、クラフト、摩耗した装備の修理、休息ができる――長い旅を、管理可能な小さな停止の連続に変えるループだ。限られたプレイセッションをやりくりするグループにとって、その自然な区切りは静かな利点となる。

## 評決：Wyldheartは追う価値があるか？

初期ビルドに基づくなら、Wyldheartは今後のラインナップの中でも特に思慮深く位置づけられた協力型RPGの1つだ。最大級のサバイバルゲームを規模で超えようとはしておらず、クリア可能であろうとしている。それは爽やかな目標であり、希望メカニクスが「剣のあるサバイバルゲーム」以上の本物のアイデンティティを与えている。

| 強み | 考慮点 |
|---|---|
| 実際にクリアできる10時間キャンペーン | 100時間の大作を求めるプレイヤーには短く感じられるかもしれない |
| キャッチアップ機構付きドロップイン協力プレイ | シームレスに感じるには依然としてある程度の調整が必要 |
| クラスレスビルドと柔軟なロードアウト | 明確なガイダンスがないと選択麻痺 |
| 希望メカニクスが本物の緊張感を加える | 無謀なグループや方向音痴のグループには厳しい |
| 手作りイベント付きヘクスマップ | ダンジョンにミニマップがないことは一部プレイヤーを苛立たせる |

正直な注意点が2つある。プレス向けに公開されたビルドは、声優を含む物語面と演出面の磨き込みの多くを欠いていたため、ストーリーの質は依然として未証明だ。そして、ゲームが発表されたばかりでプレイヤー体験は限られており、頼れる大規模なコミュニティの総意はまだ存在しない。実際に触ったセッションをより深く知りたいなら、[RPGamerの初期Wyldheartインプレッション](https://rpgamer.com/2026/03/wyldheart-impression/)が同じビルドを詳細に扱っている。

## FAQ

**Wyldheartのキャンペーンはクリアまでどれくらいかかりますか？**
Wayfinder Studiosはキャンペーンのメインストーリーに約10時間、さらに約15時間の任意サイドコンテンツを目標としている。毎週短時間で遊ぶグループなら、何か月もかからず数回のセッションで冒険を終えられるはずだ。

**Wyldheartのキャンペーンには何人まで参加できますか？**
最大4人まで一緒に冒険でき、ドロップイン／ドロップアウト、クラウド共有セーブ、グループXPに対応する。難易度はプレイヤー人数に応じてスケールするため、2人でも4人でもプレイ可能な状態が保たれる。

**Wyldheartでキャラクターが死亡するとどうなりますか？**
希望ハートを使い果たした状態で再び戦闘不能になると、キャラクターは死亡する。仲間が寺院または復活スクロールで蘇生できるほか、プレイヤーが新しいキャラクターを作成し、最終的にはその新たな英雄で元のキャラクターを救出することもできる。

**Wyldheartはサバイバルゲームですか、それともテーブルトップRPGですか？**
両方から借りている。戦利品を漁り、武器の耐久度を管理し、キャンプで料理と修理を行うループは協力型サバイバルゲームから来ており、祖先、背景、希望ハート、サイコロなしのキャンペーンアークはテーブルトップRPGから直接引かれている。このWyldheartレビューは、より多くのプレイヤー体験と発売後の詳細が入手でき次第更新される。
