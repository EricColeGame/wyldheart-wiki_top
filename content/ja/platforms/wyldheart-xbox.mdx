## WyldheartがXboxにぴったり合う理由

XboxプレイヤーがWyldheartについて尋ね続けるのは、話題のための話題ではない。このゲームの機能リストが、コンソールの協力プレイグループが実際に求めているもののチェックリストのように読めるからだ。

| Wyldheartの機能 | Xboxに合う理由 |
| --- | --- |
| 1〜4人のオンライン協力プレイ | コンソールのパーティは2〜4人の友人がボイスチャットで集まる形が基本 |
| シームレスな途中参加・途中退出 | 誰かがセッション途中で抜けてもロビーをリセットする必要がない |
| クラウド共有セーブ | メンバーが1人オフラインでもパーティはプレイを続けられる |
| グループXPと難易度スケーリング | スケジュールが合わなくても誰も取り残されない |
| 約10時間のストーリーキャンペーン | 100時間の拘束ではなく、数回のゲームナイトに収まる |
| 15時間の任意コンテンツ | メインアークをクリアしたグループ向けの追加的な深み |
| クラスレスのスキルツリー（50以上のスキル） | 4人が本当に異なる役割を構築できる |
| 発見できる100以上のエリア | 複数回のセッションを通じても探索が新鮮に保たれる |

際立っているのはスケジュールの観点だ。Wayfinder StudiosはWyldheartを、忙しい大人のためのゲームとして明確に位置づけている。キャンペーンは40時間目で投げ出すのではなく、クリアされるよう設計されている。クラウド共有セーブとグループXPがあれば、4人パーティは2人がログインできない週を乗り切れる。これはまさに、Xboxの協力プレイグループが長編RPGで直面する問題であり、コミュニティのスレッドでWyldheartのXboxに関する疑問が繰り返し浮上する理由でもある。

舞台設定もまた魅力だ。Wyldheartはよくあるグリムダークの型ではなく、妖精の伝承を取り入れた神話的ファンタジーに傾いており、プレイヤーはFreefolk、Grimhorn、Mosslingという3つの種族と、19種類のバックグラウンドから選ぶ。短く、奇妙で、キャラクター主導のキャンペーンは、すでに広大なオープンワールドRPGが時間を奪い合っているコンソールのオーディエンスにこそよく合う。
