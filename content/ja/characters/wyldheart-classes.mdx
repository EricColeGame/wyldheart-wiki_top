Wyldheartのクラスを探したことがあるなら、おそらく何か奇妙なことに気づいたはずです。このゲームには、実のところクラスが存在しません。Wayfinder Studiosによる協力プレイ型ファンタジーRPG、Wyldheartは、固定されたジョブを捨て去り、完全にクラスレスなスキルシステムを採用しています。この一つの設計判断が、ヒーローの作り方に関するすべてを変えてしまいます。だからこそ、Wyldheartのクラスを検索する多くのプレイヤーが、同じ疑問にたどり着くのです——「で、実際には何をプレイすればいいの？」

短く答えるなら、好きなスキル、武器、装備の組み合わせをプレイすればいいのです。もう少し詳しく言うと、5つのスキルツリー、いくつかの武器クラス、3つの祖先、そしてダンジョンに足を踏み入れる前にキャラクターへ物語を与える19の背景が関わってきます。このガイドでは、このシステムがどう機能するのか、実際にどのような役割が生まれるのか、そして1〜4人の協力プレイで機能するパーティをどう計画するのかを順を追って見ていきます。

## なぜWyldheartのクラスはクラスレスなのか（そしてそれが重要な理由）

ほとんどのファンタジーRPGは、戦闘がどんな感触なのかを理解する前に、最初の5分以内にアイデンティティを固定するよう求めます。Wyldheartは逆を行きます。あなたはダンジョンに放り込まれた卑しい農民として始まり、自分の町を守るために古のケルウィンのレリックの一つを取り戻す任務を負います。誰もあなたに称号やギルドのバッジ、あらかじめ決められた役割を渡したりはしません。

代わりにあなたは祖先を選び、ロールプレイのフレーバーとして19の背景から一つを選び、その後、5つのツリーにまたがる50以上のRPGスキルを通じて外へと構築していきます。その結果、「あなたのクラスは何ですか？」という質問に対して何十もの有効な答えが存在するゲームになります——そしてそのほとんどはハイブリッドです。

| よくあるプレイヤーの質問 | Wyldheartの答え方 |
|---|---|
| 「どのクラスを選べばいい？」 | クラスの選択はありません——祖先と19の背景から一つを選びます |
| 「一つの役割に縛られる？」 | いいえ：50以上のRPGスキルが5つの柔軟なクラスレスツリーに存在します |
| 「回復、魔法、近接を混ぜられる？」 | WeaponryとMagicにポイントを分けることを止めるものは何もありません |
| 「新しいことを試すには？」 | 武器は戦闘中に素早く切り替わり、ツリーは実験向けに作られています |
| 「ビルドを変えるにはリロールが必要？」 | キャンペーンは意図的に短いので、新しいアイデアを試すのは低コストです |

この最後の点は、聞こえる以上に重要です。キャンペーンはおよそ10時間のストーリーと約15時間の任意コンテンツで構成されているため、一周を終えて、自分が何を好んだかを学び、何百時間も無駄にしたと感じることなく新しく始められます。

## すべてのWyldheartビルドを形作る5つのスキルツリー

クラスの代わりに、Wyldheartは5つのスキルツリーを提供します：**Adventuring**、**Survival**、**Dungeoneering**、**Weaponry**、**Magic**です。公式の[Wayfinder StudiosによるWyldheartサイト](https://wyldheartgame.com/)では、これらを「完全に柔軟」と説明しており、つまり一つのツリーを深く特化することも、複数にまたがる巧妙な組み合わせを作ることもできます。

| スキルツリー | おおまかに扱う内容 | サポートしがちなビルド |
|---|---|---|
| Adventuring | 世界の探索、クエストの発見、町や荒野の移動 | スカウト、クエスト追跡者、ユーティリティキャラクター |
| Survival | 素材の採取、クラフト、料理、過酷な地域への耐性 | クラフター、サポートプレイヤー、長期探索者 |
| Dungeoneering | 遺跡やダンジョンそのもの、そして中で待ち受ける危険 | 罠に敏感な探索者とレリックハンター |
| Weaponry | 近接および遠距離の戦闘技術 | 前線のブルーザーとスカーミッシャー |
| Magic | 呪文詠唱と超自然的な効果 | 純粋なキャスターとハイブリッドなスペルブレード |

実践的な目安として：5つのツリーすべてに均等にポイントを振ると、たいてい何においても凡庸なキャラクターが出来上がります。最も満足度の高いビルドは、2つのツリーを背骨として選び、ユーティリティのために3つ目に少し手を伸ばします。剣を振り回しながら調合物を投げたいなら、SurvivalとWeaponryは自然な組み合わせです。遠距離から殲滅しつつダンジョンでも生き残りたいなら、MagicとDungeoneeringがダメージとナビゲーションの両方をカバーします。

ツリーはクラスレスなので、「最良の」組み合わせは完全にあなたのグループ次第です。ソロプレイヤーは自己完結性から恩恵を受け、4人パーティの一員は狭い専門性に全力を注ぎ、チームメイトに隙間を埋めてもらう余裕があります。

## 武器クラス：伝統的なWyldheartクラスに最も近いもの

ビルドを固定するための具体的な何かが必要なら、武器クラスを見てください。Wyldheartは**習得すべき5つ以上のユニークな武器クラス**をうたっており、戦闘はそれらを流動的に切り替えることを中心に設計されています。一回の戦闘中に、近接武器から弓に切り替え、呪文を唱え、致命的な調合物を投げつけることができます——そのすべてをメニュー画面を開かずに行えます。

| 戦闘スタイル | プレイの感触 | 相性の良い組み合わせ |
|---|---|---|
| 近接武器 | 距離を詰めて前線で打ち合う | 持ちこたえるならWeaponry + Survival |
| 遠距離武器 | 敵を一定の距離に保ち、じわじわ削る | 機動力ならWeaponry + Adventuring |
| 呪文詠唱 | 安全な距離からバーストダメージと魔法のユーティリティ | Magic + 好きなものなんでも |
| 投擲調合物 | 戦闘中の錬金術ダメージと妨害 | ハイブリッド錬金術師ならSurvival + Magic |
| 絶え間ない切り替え | コミットする代わりに戦況に応じて道具を変える | 好きな2つのツリー |

これが、「Wyldheart classes」がやや誤解を招く検索語である理由です。ゲームが実際に与えるのは戦闘ツールキットです。あなたの「クラス」は、ダンジョンの扉が開いたときにたまたま手にしているものです——そして切り替えが速いため、それは戦闘中に変わり得ます。

## 祖先と背景：ビルドが本当に始まる場所

スキルポイントが登場する前に、Wyldheartはあなたのキャラクターが誰なのかを問います。3つの祖先——**Freefolk**、**Grimhorn**、**Mossling**——から一つを選び、その後、ロールプレイのフックと物語の始まり方を形作る19の背景から選びます。

| 選択 | オプション | もたらすもの |
|---|---|---|
| 祖先 | Freefolk、Grimhorn、Mossling | キャラクターのアイデンティティ——誇り高きFreefolk、そびえ立つGrimhorn、小さなMossling |
| 背景 | 19の卑しい背景 | ロールプレイのフレーバーと「これ以前のあなたは誰だったのか」という問い |
| スキル | 5つのツリーにまたがる50以上のRPGスキル | ビルドの機械的な背骨 |
| 武器クラス | 5つ以上のユニーククラス | 瞬間ごとの戦闘の感触 |

公式資料では、これらは厳格なステータスパッケージではなく、フレーバー優先の選択として位置づけられています。実際には、最もロールプレイが楽しい祖先と背景を選び、重労働はスキルツリーに任せるべきだという意味です。最適化に頭を悩ませるタイプなら、これをクラス選択画面として扱いたい衝動に抗ってください——そうではありません。

注目に値するのは、Wyldheartがフェイの民間伝承に浸った神話的ファンタジー世界を舞台にしており、Curve Gamesとの提携でパブリッシュされていることです。デモではWhisperwood地域を探索し、挑戦的なダンジョンに挑めます。これはリリース前に祖先とツリーがどう相互作用するかを感じ取る最速の方法です。

## Wyldheartクラスのためのパーティビルドと協力プレイのヒント

ここがクラスレス設計が本当に輝くところです。Wyldheartはソロプレイと最大4人のオンライン協力プレイをサポートし、シームレスな途中参加・退出、クラウド共有セーブ、グループXP、難易度スケーリングを備えています。つまり、ゲームナイトを逃しても誰も置き去りにされません——パーティは続行でき、不在のプレイヤーはレベルが上がった状態で戻ってきます。

### 協力プレイパーティをカバーする5つのコミュニティ風の役割

これらは公式クラスではありません。スキルポイントで目指せる役割ラベルだと考えてください。

| 役割ラベル | 主要ツリー | 武器の焦点 | グループに役立つ理由 |
|---|---|---|---|
| 前線ブルーザー | Weaponry | 近接 | 敵の注意を引きつけ、柔らかいビルドが動けるようにする |
| 遠距離スカーミッシャー | Weaponry | 弓と投擲武器 | ブルーザーがカバーできない角度から敵を罰する |
| 呪文詠唱者 | Magic | 呪文 | 優先ターゲットをバーストで倒し、ユーティリティを追加する |
| 錬金術サポート | Survival | 調合物 | クラフト、料理、妨害投擲でパーティに物資を供給する |
| ダンジョンスカウト | Dungeoneering | 最も軽いものなら何でも | 他のパーティメンバーが見逃す遺跡、クエスト、ルートを見つける |

### 実践的な協力プレイのアドバイス

- **難易度のスケーリングに任せましょう。** Wyldheartはパーティサイズに応じて遭遇の難易度を調整するので、4枠すべてを埋めないからといって2人や3人が密かに罰せられることはありません。
- **クラフトの役割を割り当てましょう。** パーティのための料理や装備のアップグレードはソロの雑用ではなくパーティ全体の利益です——誰かが担当すべきです。
- **短いキャンペーンを受け入れましょう。** 約10時間のストーリーと15時間の任意コンテンツがあるため、キャンペーンは一つのビルドを永遠に完成させるよりも、2つか3つの異なるビルドを試す絶好の口実になります。
- **保険としてクラウドセーブを使いましょう。** 一人が参加できなくても、グループはその人なしで続行でき、誰も進行を失いません。
- **すべてを重複させないこと。** Wyldheartのクラスは伝統的な意味では存在しないため、弱いパーティへの最速の道は4人の同じ万能選手です。ツリーを分けましょう。

## FAQ

**Wyldheartのクラスはそもそも存在しますか？**
伝統的な固定されたジョブクラスとしては存在しません。Wyldheartは5つの柔軟なスキルツリー——Adventuring、Survival、Dungeoneering、Weaponry、Magic——に加えて自由に切り替えられる5つ以上の武器クラスで構築されたクラスレスシステムを使用しています。あなたの実効的な「クラス」は、あなたが組み立てる組み合わせです。

**Wyldheartにはいくつの武器クラスがありますか？**
ゲームは習得すべき5つ以上のユニークな武器クラスをうたっており、近接武器、遠距離武器、呪文詠唱、投擲調合物をカバーしています。戦闘中に切り替えられるため、ほとんどのプレイヤーは最終的に複数に熟達します。

**どの祖先や背景を選ぶべきですか？**
確認された「最良の」選択肢はありません。Freefolk、Grimhorn、Mosslingは主にキャラクターアイデンティティの選択として提示され、19の背景はロールプレイのフックです。語りたい物語のものを選び、その後、楽しめる戦闘スタイルに合わせてスキルを構築しましょう。

**後でビルドを変更できますか、それとも固定されますか？**
スキルツリーは完全に柔軟と説明されており、キャンペーンは意図的に小分けされて約10時間のストーリーと15時間の任意コンテンツで構成されています。ビルドがしっくりこないなら、一周を終えて新しいキャラクターを始めることは、大きな時間投資ではなく現実的な選択肢です。

**Wyldheartはソロプレイヤーに向いていますか？**
はい——このゲームはソロプレイと最大4人のオンライン協力プレイの両方のために設計されており、難易度はスケーリングします。ソロプレイヤーはより広いスキルの広がりを求めるでしょうが、協力プレイグループは徹底的に特化する余裕があります。

Wyldheartは現在EpicとSteamでPC向けにリストされており、リリース日はまだ発表されていないため、Wyldheartのクラスとスキルツリーに関する詳細は、デモやショーケースが展開されるにつれて進化し続けると予想されます。今のところ、最も賢いアプローチはシンプルです：楽しいと思える祖先と背景を選び、構築の軸となる2つのスキルツリーを選び、武器については柔軟であり続けましょう。クラスを渡すことを拒むゲームでは、あなたのビルドはあなたが作り上げたものそのものです。
