## Tips for Your First Beta Session

The beta build is deliberately unfinished, so a little preparation goes a long way.

- **Bring a friend if you can.** Wyldheart is built as a co-op experience, and testing with a full party surfaces far more than solo play does.
- **Report bugs with detail.** Screenshots, reproduction steps, and your system specs turn a complaint into a fix.
- **Back up your settings.** In-development builds occasionally reset configuration files between patches.
- **Read patch notes before you play.** The studio updates the build continuously, so last week's bug may already be gone.
- **Don't treat progression as permanent.** Pre-launch builds routinely change save structures, so enjoy the journey rather than grinding for keeps.

| Common Beta Pitfall | Smarter Approach |
|---|---|
| Assuming beta progress carries into 1.0 | Play for feedback, not for a head start |
| Judging balance on day one | Revisit after each patch |
| Reporting "it's broken" with no context | Include steps, clips, and specs |
| Ignoring the community channels | Patch news lands there first |
